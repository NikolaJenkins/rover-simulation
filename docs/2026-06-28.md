## Goal

Write more complicated sequence to tell robot to autonomously drive forward and then turn left repeatedly.

# Issues

Simply using the robot's orientation.z value in the calculation didn't work.

# Solution

Since ROS's orientation class uses quaternions rather than simple roll/pitch/yaw values, an intermediary conversion was required to retrieve the robot's yaw value.
